# CyberSecurity-Projects

A collection of hands-on cybersecurity projects spanning defensive (blue team) and offensive (red team) domains. Each project documents the objective, methodology, tools used, evidence, and key findings.

## Project Categories

| Category | Focus Areas | Example Tools |
|----------|-------------|---------------|
| Defensive (Blue Team) | Threat detection, log analysis, incident triage | Splunk, Wireshark, Suricata, Wazuh |
| Offensive (Red Team) | Reconnaissance, exploitation, privilege escalation | Kali Linux, Nmap, Metasploit, Burp Suite |
| Analysis & Forensics | PCAP analysis, malware triage, IOC extraction | Wireshark, VirusTotal, CyberDefenders |
| General Security | Web app security, password analysis, OS hardening | OWASP ZAP, John the Ripper, Nikto |

## Purpose
To build and demonstrate practical cybersecurity skills through reproducible labs, clear documentation, and evidence-based analysis. Projects are added as I explore new tools, techniques, and attack/defense scenarios.

## Skills Demonstrated
- Network reconnaissance and scanning
- Log analysis and SIEM alert triage
- Phishing and IOC investigation
- Web application vulnerability testing
- Password and credential attack analysis
- IDS/EDR alert correlation
- Incident documentation and reporting

## Disclaimer
All projects are performed in isolated, self-owned lab environments for educational purposes only. No unauthorized systems are targeted.
